# TrackingApp

TrackingApp is a personal reading tracker for manga, manhwa, manhua, comics, novels, web novels, and books. It helps users manage their libraries, track reading progress, rate titles, write reviews, maintain reading history, and discover new titles through personalized AI-powered recommendations.

## Tech Stack

- **Frontend:** React, TypeScript
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma

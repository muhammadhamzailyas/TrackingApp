# TrackingApp

TrackingApp is a personal reading tracker for manga, manhwa, manhua, comics, novels, web novels, and books.

## Key Features

- **Library Management:** Organize and track your personal reading library.
- **Progress Tracking:** Keep track of your reading progress across different titles.
- **Ratings & Reviews:** Rate your favorite titles and write detailed reviews.
- **Reading History:** Maintain a comprehensive history of what you've read.
- **AI Recommendations:** Discover new titles through personalized AI-powered recommendations.

## Tech Stack

- **Frontend:** React, TypeScript
- **Backend:** Node.js, Express, TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma
